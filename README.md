# Lightlee proxy (Netlify Function)

Прокси между лаунчером и DeepSeek. Ключ лежит ТОЛЬКО в переменных окружения Netlify, в лаунчер он не попадает.

## Установка (отдельный сайт — самый простой путь)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. На netlify.com: Add new site → Import an existing project → выберите репозиторий (настройки сборки не нужны).
3. Site configuration → Environment variables → Add:
   - `DEEPSEEK_API_KEY` = ваш ключ (вставляете сами, никому его не отправляйте);
   - необязательно `DEEPSEEK_MODEL` (по умолчанию `deepseek-chat`) — актуальное имя проверьте в документации DeepSeek.
4. Deploys → Trigger deploy. Адрес функции: `https://ИМЯ-САЙТА.netlify.app/.netlify/functions/lightlee`.
5. Впишите его в `config.js` лаунчера, поле `LIGHTLEE_URL`.

Если хотите на уже существующем сайте everlighte.netlify.app: сайт должен деплоиться из Git или через Netlify CLI (при загрузке перетаскиванием функции не работают). Скопируйте в его репозиторий `netlify/functions/*` и `netlify.toml`.

## Что править
- `netlify/functions/knowledge.js` — база знаний (правила, адреса, FAQ). После правки — новый деплой.
- `netlify/functions/lightlee.js` — характер и ограничения Лайтли (`SYSTEM`), лимиты (`LIMIT`, `WINDOW`, `DAILY`).

## Защита и ограничения
- Лимит запросов считается в памяти функции и может сбрасываться при её перезапуске. Поэтому в кабинете DeepSeek обязательно задайте месячный лимит расходов.
- Ответ ограничен ~350 токенами, вопрос 600 символами, лог 4000 символами.
- Если ключ случайно попал в чужие руки — перевыпустите его в кабинете DeepSeek.
